# Changelog

All notable updates to NakibSEO are documented in this file.

## [1.0.0] — Initial Release

### Features

* On-page SEO inspection
* Page title and meta description inspection
* Heading and H1 inspection
* Page text and content inspection
* Link inspection
* Keyword search and highlighting
* In-page SEO toolbar
* English and Arabic language support

### Availability

NakibSEO is available on the Chrome Web Store.

For installation, visit the [NakibSEO Chrome Web Store page](https://chromewebstore.google.com/detail/nakibseo/obnjjeoighjipilokheneakbdcfbjmfk).

### Privacy

NakibSEO performs page inspection locally in the browser and does not require a remote SEO analysis service to process the page.

See the [Privacy Policy](https://www.webcava.com/p/nakibseo-privacy.html) for more information.
